# text2mp3

## アプリケーションの概要

edge-ttsを利用したttsツールです。
下記を可能としています。

edge-ttsっているため下記が可能です。
- 流暢な読み上げ
- 高速の音声変換
- 字幕ファイルの作成
- 多言語での読み上げ

またtext2mp3として下記を可能に実装をしています。
- yamlでの変換文章の記載
- 辞書登録
- 行間の間を取る時間の調整
- 行ごとの音量・速度・音程の調整

## こんなことをする際におすすめ

### YouTubeなどの動画作成

辞書機能があることによって、
専門用語なども平仮名入力することなく
読み上げを行うことが可能となります。

字幕ファイルを作成していくれるため、
字幕をつけた動画の作成も容易に行えます。
また、動画編集時に話している内容に
合わせて映像を切り替えることが容易になります。

また、yamlのリスト形式で1つのファイルで
音声モデルを切り替えながら
音声変換が可能です。
そのため、会話形式の音声の作成も容易に行えます。

## 導入方法

本ソフトウェアでは、podman を利用しています。
images 自体はDocker Hubにあげているため、
下記コマンドの実施で利用可能となります。

### debian系 の場合

下記コマンドを実行します。

``` bash
sudo apt install podman
podman pull docker.io/sabotagecla6/text2mp3
git clone https://github.com/sabotage-cla6/text2mp3.git
cd text2mp3
chmod u+x text2mp3
```

### Windowsの場合

1. WSLを有効にする
2. Podman Desktopをインストールする
3. pwsh で `podman pull docker.io/sabotagecla6/text2mp3` を実行してイメージを取得
4. このサイトのCodeをダウンロード

## 使い方

現時点、変換元のテキストファイル、辞書ファイル、変換後の音声ファイル、字幕ファイルはすべて同じディレクトリに保存している必要があります。

### debian系 の場合

1. git からcloneしたディレクトリに移動
1. 下記コマンドを実行
``` bash
./text2mp3 -v [音声/字幕を出力したいフォルダ] -i [変換元のテキストファイル名] -d [辞書ファイルのファイル名] -o [出力する音声ファイル名] -s [出力する字幕ファイル名]
```

手軽に試してみたい場合は下記のコマンドを入力してみてください。

``` bash
./text2mp3 -v ./ -i input.yaml -o output.mp3 -d dict.yaml -s output.srt
```

### Windowsの場合

1. git からcloneしたディレクトリに移動
2. 1. 下記コマンドを実行
``` bash
./text2mp3.ps1 -v [音声/字幕を出力したいフォルダ] --inputfile [変換元のテキストファイル名] -dict [辞書ファイルのファイル名] -output [出力する音声ファイル名] -srtfile [出力する字幕ファイル名]
```

# 使い方詳細

## オプション

i/inputfile：変換するテキストを記載したファイル
o/output   ：出力する音声ファイル名
s/srtfile  ：出力する字幕ファイル名（省略した場合はoutputのmp3がsrtに置き換わって出力される）
v/volumn   ：inputfileの格納されているフォルダ

## inputfileの記載方法

talkの要素に話す内容を記載します。
最初にどの声のID（口述）を記載し、:で区切って、話す内容を記載します。
複数行記載する場合には、: の後に | を記載してから記載します。
インデント（字下げ）が必要ですので、サンプルをを真似して記載してください。

特定の分だけ、音量を変えたり、スピードを変えたり、声の高さを変えることができます。
その場合には、テキスト入力後に、音量やスピードに関する情報を記載します。
記載の内容は、次で説明します。

最後に、voices要素の中に、声の内容を定義します。
idの要素が、talk要素の話す内容の前につける識別子です。
voice要素は、text2mp3で対応している声の種類です。
voice要素の続けて、volumn要素を追加すると声の大きさを
rate要素を追加すると、読み上げのスピードを
pitch要素を追加すると、声の高さを変更することができます。


# 注意事項

音声変換には、Edgeの読み上げ機能で利用しているサービスに接続します。
そのため、ネットワーク通信が発生します。
